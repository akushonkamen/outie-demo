# OUTIE — 线下养宠小游戏（软件原型阶段）

把参加过的线下活动，变成宠物身上可以展示的限定纪念。
用户到现场打卡，给宠物收集限定造型；集齐三个地点，解锁活动限定形态。

> 产品定位（当前主张）：**「把你参加过的活动，变成宠物身上可以展示的限定纪念。」**
> 不是发明"线下养宠"（Tamagotchi Lab Tama、Pikmin Bloom 地点收集已覆盖相近结构），
> 而是做一种更具体的活动体验：奖励必须能看见"活动名字、日期和出处"。

## 本轮范围（V1）

- 1 场活动、1 只宠物、3 个打卡点、5 套形象、2 个主页面
- 核心循环：领宠物 → 到地点打卡 → 拿造型 → 换上 → 集齐三个 → 解锁限定形态
- 三站：音乐区（耳机）→ 展览区（眼镜）→ 市集区（背包）→ 限定形态「出逃星人」
- 移动端优先的网页；匿名身份；进度只存当前浏览器（localStorage）
- "进化"= 解锁一个新形态，不做等级 / 战斗力 / 技能树；造型可随时换回

## 本轮明确不做

- 好友、聊天、附近的人、排行榜、连续签到、饥饿值、AI 生成宠物、用户上传素材
- 独立分享系统（能打开宠物页给别人看、自己截图即可，先观察展示欲）
- 硬件 / 挂件 / 蓝牙 / NFC / 定位 / 防作弊（静态二维码仅适合低风险玩法测试）
- 主办方自助后台（活动、地点、五套素材由开发配置）

## 本轮要验证的三件事

1. **有没有看懂**：不靠工作人员解释，能否说出"打卡拿造型，集齐解锁新形态"
2. **有没有想继续**：拿到第一个奖励后，会不会主动查看下一个地点
3. **有没有想展示**：会不会主动换上、给同行的人看、问别人造型怎么拿

- 玩法 1:1 覆盖 V1 循环：领养取名 → 模拟打卡 ×3 → 收造型换装 → 集齐进化
- 视觉方向（2026-09-27 用户定稿）：**墨水屏 + 8-bit 像素**。
  纸质底色 + 近黑墨色 + 有限低饱和色（蓝/红/黄/绿）、像素点阵宠物（22×16 网格，
  5 套形态共用身体 + 配件图层）、像素字母表（SVG 点阵字，无外部字体）、假像素二维码、
  硬边框无圆角无阴影、步进式动画（steps）
- 文案基调同步改掉：删除卖萌用语（"搭子/捡造型/小快乐"等），
  全部改为中性设备式表达；主要按钮沿用最初规格的措辞（"去拿新造型""穿上"）
- 进度存 localStorage（key: `outie.singleplayer.v1`），设置里可改名 / 清档重玩
- 打卡为按钮模拟，不读位置；无网络请求、无账号、无硬件

## 下一步（按优先级）

1. **像素 IP 打磨**：当前像素宠物是"能用"级别（22×16、共用身体 + 配件图层），
   下一轮按"统一原创 IP"标准精修 5 套形态的辨识度和表情，为彩色墨水屏挂件做资产准备
2. **奖励的"出处感"**：造型里带上活动名 / 日期，让换装表达"我去过这场"，
   并验证用户是否想带着同一只宠物参加下一场活动
3. **展示欲假入口**：先做"生成宠物卡片 / 分享图片"的假入口，测用户有没有展示欲
4. 真实活动试点前的轻量后台（匿名身份 + 打卡去重 + 活动有效期校验）
